# stock_quant

## Source system
This table originates from an Odoo ERP system. The naming convention (e.g., `quant`, `product_id`, `location_id`, `create_uid`) and the specific pattern of audit fields (`create_date`, `write_date`, `write_uid`) are characteristic of the Odoo inventory management module.

## Functional process 
This table supports the inventory valuation and stock tracking process. It maintains the current state of stock levels across various locations, tracking quantities on hand, reserved quantities for pending orders, and inventory adjustment discrepancies.

## Description
One row in this table represents a specific quantity of a product held in a particular location, potentially associated with a specific lot, package, or owner. As a staging table, it serves as a raw, landed copy of the Odoo `stock.quant` model, capturing the real-time snapshot of inventory levels and their associated metadata.

## Caveats for downstream consumers

- **Timestamps:** All timestamps (`in_date`, `create_date`, `write_date`) are stored in UTC as per Odoo standard behavior.
- **Data Sensitivity:** Contains no direct PII, but `owner_id` may link to sensitive partner/customer records.
- **Soft Deletes:** This table does not implement soft deletes; it represents the current state of the inventory.
- **Quantity Precision:** `quantity` and `reserved_quantity` are `NUMERIC` types; ensure appropriate rounding is applied when aggregating for financial reporting.
