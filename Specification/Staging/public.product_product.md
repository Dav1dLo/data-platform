# product_product

## Source system
This table originates from Odoo ERP. The naming convention `product_product` (representing product variants) paired with `product_tmpl_id` (the product template), `default_code` (SKU), and Odoo-specific audit columns like `create_uid` and `write_uid` are characteristic of the Odoo product module architecture.

## Functional process 
This table supports the inventory and product management lifecycle, specifically handling individual product variants. It tracks physical attributes (weight, volume), identification codes (barcode, SKU), and status flags for items that exist as distinct stockable or sellable units within the Odoo catalog.

## Description
One row represents a single product variant, which is a specific configuration of a base product template (e.g., a specific size or color of a shirt). This is a raw staging table containing a direct copy of the Odoo `product.product` model, serving as the foundation for downstream product dimension modeling.

## Columns

| Column | Type | Nullable | Meaning | Notes |
| :--- | :--- | :--- | :--- | :--- |
| id | INTEGER | false | Surrogate primary key | Sequence-generated by Odoo. |
| product_tmpl_id | INTEGER | false | Foreign key to product template | Links to the base product definition. |
| create_uid | INTEGER | true | Creator user ID | Reference to the user who created the record. |
| write_uid | INTEGER | true | Last modifier user ID | Reference to the user who last updated the record. |
| default_code | VARCHAR | true | SKU or internal reference | The business-facing product code. |
| barcode | VARCHAR | true | EAN/UPC barcode | Used for scanning in warehouse operations. |
| combination_indices | VARCHAR | true | Variant attribute mapping | Internal Odoo string representing attribute combinations. |
| standard_price | JSONB | true | Cost price data | Often contains currency and cost history. |
| volume | NUMERIC | true | Product volume | Physical dimension for logistics. |
| weight | NUMERIC | true | Product weight | Physical dimension for logistics. |
| active | BOOLEAN | true | Soft-delete flag | If false, the product variant is archived. |
| can_image_variant_1024_be_zoomed | BOOLEAN | true | UI configuration flag | Odoo-specific image display setting. |
| write_date | TIMESTAMP | true | Last update timestamp | UTC timestamp of the last modification. |
| create_date | TIMESTAMP | true | Creation timestamp | UTC timestamp of record creation. |
| lot_properties_definition | JSONB | true | Lot/Serial tracking config | Schema for tracking properties on this variant. |

## Keys

- **Primary key (inferred):** `id`
- **Foreign keys (inferred):** 
    - `product_tmpl_id` → `product_template.id`: This column links the variant to its parent product template definition.
- **Natural keys (inferred):** 
    - `default_code`: Commonly used as the unique SKU across the business.
    - `barcode`: Unique identifier for scanning purposes.

## Caveats for downstream consumers

- **Soft Deletes:** The `active` column acts as a soft-delete flag; ensure queries filter by `active = TRUE` unless historical data is required.
- **Timestamps:** `create_date` and `write_date` are stored in UTC.
- **JSONB Data:** `standard_price` and `lot_properties_definition` contain nested structures; use PostgreSQL JSONB operators (e.g., `->>`) to extract specific values.
- **PII:** This table generally does not contain PII, but `create_uid` and `write_uid` link to internal user tables which may contain employee names or emails.
