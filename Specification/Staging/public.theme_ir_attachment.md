# theme_ir_attachment

## Source system
This table originates from an Odoo ERP system. The naming convention `ir_attachment` is a standard pattern used by the Odoo framework to manage file attachments and binary data associated with various business objects.

## Functional process 
This table supports the document management and asset storage process within the ERP. It acts as a central registry for files, images, or binary blobs linked to other records, facilitating the attachment of metadata and URLs to business entities.

## Description
One row in this table represents a single file attachment or binary asset record. It serves as a raw landing copy of the Odoo `ir.attachment` model, capturing the metadata, file naming, and storage location (URL) for assets within the staging layer.
