# account_account

## Source system
This table originates from an Odoo ERP system. The naming convention (`account_account`), the use of `JSONB` for localized fields like `name`, and the presence of standard Odoo audit columns (`create_uid`, `write_uid`, `create_date`, `write_date`) are characteristic of the Odoo framework's accounting module.

## Functional process 
This table supports the General Ledger and Chart of Accounts management process. It defines the structure of the accounting system by storing the master list of accounts (e.g., assets, liabilities, equity, income, and expenses) used for financial reporting and transaction classification.

## Description
One row in this table represents a single account within the organization's Chart of Accounts. This is a raw landed copy from the staging layer, containing both system-level metadata and configuration flags that determine how an account behaves during reconciliation and financial reporting.
