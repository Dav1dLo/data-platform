# account_account

## Source system
This table originates from Odoo (formerly OpenERP), an open-source ERP system. The naming convention `account_account` and the presence of columns like `create_uid`, `write_uid`, and `JSONB` fields for multi-language support are characteristic of the Odoo ORM's database schema.

## Functional process 
This table supports the General Ledger and Chart of Accounts management process. It defines the specific accounts (e.g., Assets, Liabilities, Equity, Revenue, Expenses) used for financial reporting and transaction categorization within the accounting module.

## Description
One row represents a single account within the organization's Chart of Accounts. It serves as a raw landed copy of the Odoo `account.account` model, capturing the configuration, classification, and metadata for financial accounts used in the staging layer.

## Caveats for downstream consumers

- **Data Types:** `name` and `code_store` are `JSONB` fields; you will need to use PostgreSQL JSON operators (e.g., `->>`) to extract values for reporting.
- **Timestamps:** Timestamps are stored in the database's local time (typically UTC in Odoo deployments), but verify against the application server configuration.
- **Soft Deletes:** Odoo typically uses the `active` column (not present here) for soft deletes; check if `deprecated` serves as a functional equivalent for your reporting needs.
- **PII/Sensitivity:** This table contains financial configuration data; while not containing direct PII, it is highly sensitive for financial audit purposes.
