# pos_payment_method

## Source system
This table originates from Odoo ERP, as evidenced by the characteristic naming conventions such as `create_uid`, `write_uid`, `company_id`, and the use of `JSONB` for localized display names. The structure is typical of Odoo's Point of Sale (PoS) module configuration tables.

## Functional process 
This table supports the Point of Sale configuration and payment processing workflow. It defines the available payment methods (e.g., cash, bank, terminal, QR code) configured for a company's PoS operations and links them to the appropriate accounting journals and receivable accounts for financial reconciliation.

## Description
One row in this table represents a single payment method configuration available within the Point of Sale system. It acts as a raw landed copy of the Odoo configuration entity, capturing the operational settings, accounting linkages, and terminal integration status for each payment type.

## Caveats for downstream consumers

- The `name` column is stored as `JSONB`; you will need to extract the relevant language key (e.g., `name->>'en_US'`) for reporting.
- Timestamps (`create_date`, `write_date`) are typically stored in UTC by Odoo.
- The `active` column acts as a soft-delete; ensure your queries filter by `active = true` unless you intend to include historical/deactivated methods.
- This table contains configuration data; it does not contain transactional payment records, only the definitions of how payments are processed.
