# product_pricelist_item

## Source system
This table originates from Odoo ERP, as evidenced by the characteristic naming conventions such as `product_tmpl_id`, `categ_id`, `create_uid`, and the use of sequence-based primary keys (`nextval` on `id`). The structure reflects the Odoo `product.pricelist.item` model, which manages complex pricing rules and discount logic.

## Functional process 
This table supports the pricing and discount engine within the sales and procurement modules. It defines how prices are calculated for specific products, categories, or global pricelists, including logic for fixed prices, percentage discounts, and price rounding rules based on minimum quantity thresholds.

## Description
One row represents a single pricing rule or discount condition applied to a product or category within a specific pricelist. This is a raw staging table containing the direct extract from the Odoo database, serving as the foundation for building downstream pricing dimensions and fact tables.

## Caveats for downstream consumers

- **Sensitive Data:** Contains no PII, but contains internal pricing strategies and margin logic which may be commercially sensitive.
- **Timestamps:** All timestamps (`date_start`, `date_end`, `create_date`, `write_date`) are stored in UTC.
- **Soft Deletes:** This table does not implement a soft-delete flag; records are typically hard-deleted in the source Odoo system.
- **Data Grain:** The `applied_on` column is critical for filtering; ensure queries account for whether the rule applies to a global scope, a category, or a specific product.
