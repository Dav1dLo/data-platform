# rating_rating

## Source system
This table originates from Odoo ERP. The naming convention (e.g., `res_model`, `res_id`, `create_uid`, `write_uid`) and the specific structure of linking ratings to generic resources via model/ID pairs are characteristic of the Odoo framework's rating module.

## Functional process 
This table supports the customer feedback and satisfaction tracking process. It captures qualitative and quantitative ratings (e.g., "Great", "Okay", "Bad") associated with various business objects such as tasks, tickets, or projects, allowing the organization to monitor service performance and internal quality metrics.

## Description
One row represents a single rating event submitted by a partner or user for a specific business resource. As a staging table, it serves as a raw, direct reflection of the Odoo `rating.rating` model, containing both the technical identifiers for the rated object and the descriptive feedback provided by the rater.

## Caveats for downstream consumers

- **Timestamps:** All `_date` and `_datetime` columns are assumed to be in UTC, consistent with standard Odoo database configurations.
- **Data Sensitivity:** The `feedback` and `publisher_comment` columns may contain PII or sensitive customer information and should be handled according to data privacy policies.
- **Soft Deletes:** This table does not appear to implement a soft-delete flag; assume records are hard-deleted if removed from the source.
- **Denormalization:** Several columns (e.g., `res_name`, `res_model`) are denormalized copies of data stored in other tables; use these for display purposes but rely on `res_id` and `res_model` for joins.
