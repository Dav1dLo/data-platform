# mail_template_preview

## Source system
This table originates from an Odoo ERP system, as evidenced by the naming convention of the primary key sequence (`mail_template_preview_id_seq`), the use of `create_uid`/`write_uid` for audit tracking, and the `resource_ref` pattern commonly found in Odoo's mail and notification modules.

## Functional process 
This table supports the email communication and notification module, specifically managing the generation and previewing of email templates before they are sent to end users. It tracks which templates are being previewed, the language context of the preview, and the associated resource reference (e.g., a specific record in the system) that the template is being rendered against.

## Description
One row represents a single preview instance of an email template, capturing the state of the template rendering for a specific resource and language. As a staging table, it serves as a raw, direct copy of the Odoo database records, providing a historical log of template previews for audit or debugging purposes.

## Caveats for downstream consumers

- **Sensitive Data:** `resource_ref` may contain internal record identifiers or model names that could be considered sensitive depending on the business context.
- **Timestamps:** All timestamps (`create_date`, `write_date`) are stored in the server's local time (typically UTC in Odoo environments), but verify against the application configuration.
- **Data Lifecycle:** This table is a staging entity; it may contain high-volume, transient data that is frequently purged or truncated in the source system.
- **Nullability:** Many fields (like `create_uid` or `lang`) may be null if the preview was generated by a system process rather than a specific user action.
