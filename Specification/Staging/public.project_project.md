# project_project

## Source system
This table originates from Odoo ERP. The naming convention (e.g., `create_uid`, `write_uid`, `company_id`, `partner_id`), the use of `JSONB` for localized fields like `name`, and the specific sequence-based primary key generation are characteristic of the Odoo framework's ORM layer.

## Functional process 
This table supports the Project Management module, specifically the project definition and configuration pipeline. It tracks project metadata, visibility settings, billing configurations, and task-related settings, serving as the central entity for project-level tracking within the business.

## Description
One row in this table represents a single project entity within the Odoo system. It captures the project's configuration, status, and administrative details at the grain of one project per record. As a staging table, it provides a raw, landed copy of the Odoo `project.project` model, intended for downstream transformation into analytical project dimensions.

## Keys

- **Primary key (inferred):** `id`
- **Foreign keys (inferred):**
    - `partner_id` → `res_partner.id` (Standard Odoo partner link)
    - `company_id` → `res_company.id` (Standard Odoo multi-company link)
    - `user_id` → `res_users.id` (Standard Odoo user link)
    - `stage_id` → `project_project_stage.id` (Standard Odoo stage link)
- **Natural keys (inferred):**
    - None. Odoo relies on the surrogate `id` for internal references.

## Caveats for downstream consumers

- **Sensitive Data:** The `access_token` should be treated as a secret and excluded from general reporting.
- **Timezones:** Timestamps (`create_date`, `write_date`) are typically stored in UTC by Odoo.
- **Soft Deletes:** The `active` column acts as a soft-delete flag; ensure queries filter by `active = TRUE` unless historical/archived data is required.
- **JSONB:** The `name` column is a JSONB object (e.g., `{"en_US": "Project Name"}`); use `name->>'en_US'` or similar to extract values.
- **Custom Fields:** Columns prefixed with `x_` are custom fields added via Odoo Studio or custom modules and may not be present in standard Odoo documentation.
