# account_account_tag

## Source system
This table originates from an Odoo ERP system, as evidenced by the naming convention (`account_account_tag`), the use of `JSONB` for multi-language name fields, and the standard Odoo audit columns (`create_uid`, `write_uid`, `create_date`, `write_date`).

## Functional process 
This table supports the financial accounting and reporting process by managing tags used to categorize accounts. These tags are often used for tax reporting, financial statement grouping, or analytical accounting, with the `applicability` column determining whether the tag is used for taxes, reports, or general account classification.

## Description
One row represents a single account tag definition used within the accounting module. The grain is one row per unique tag ID. This table serves as a raw landing copy of the Odoo `account.account.tag` model, providing the base configuration for account categorization.
