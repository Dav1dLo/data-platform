## Functional process 
This table supports the manufacturing production monitoring process, specifically tracking discrepancies between expected and actual material consumption. It acts as a detail line for warning events triggered when production orders consume materials outside of defined tolerances or expected quantities.

## Description
Each row represents a specific material consumption warning line associated with a manufacturing production order. It captures the variance between the expected quantity and the actual consumed quantity for a specific product within a production run. This is a raw staging table representing a direct copy of the underlying ERP transactional data.
