# res_partner_industry

## Source system
This table originates from Odoo (formerly OpenERP), an open-source ERP system. The naming convention `res_partner_industry` and the presence of `create_uid`, `write_uid`, and `JSONB` fields for multi-language support are characteristic of Odoo's core "Resource" (res) module architecture.

## Functional process 
This table supports the master data management of business sectors or industries. It is used to categorize business partners (customers, vendors, or contacts) into specific industry segments, which facilitates reporting, market segmentation, and CRM filtering within the lead-to-cash pipeline.

## Description
One row in this table represents a single industry classification available for assignment to business partners. As a staging table, it serves as a raw, direct reflection of the Odoo database record, capturing the industry name and its active status.

- **JSONB fields:** The `name` and `full_name` columns contain JSONB data, which likely holds multi-language translations (e.g., `{"en_US": "Technology", "fr_FR": "Technologie"}`). Use `->>` operator to extract values.
- **Soft Deletes:** The `active` column acts as a soft-delete flag. Queries should generally filter by `WHERE active = true` unless historical audit is required.
- **Timestamps:** Timestamps are stored in the database's native format; verify if the source Odoo instance is configured for UTC.
- **PII:** This table contains no sensitive PII, as it defines industry categories rather than specific customer data.
