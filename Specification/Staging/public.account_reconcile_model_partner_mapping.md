# account_reconcile_model_partner_mapping

## Source system
This table originates from an Odoo ERP system. The naming convention (`account_reconcile_model_...`), the presence of `create_uid`/`write_uid` audit columns, and the use of PostgreSQL sequence-based defaults for the `id` column are characteristic patterns of the Odoo framework's ORM layer.

## Functional process 
This table supports the automated bank reconciliation process. It maps specific reconciliation models to business partners, allowing the system to apply predefined matching rules (via regex patterns on payment references or narrations) to transactions associated with specific partners during the bank statement import and reconciliation workflow.

## Description
One row in this table represents a configuration rule that links a reconciliation model to a specific partner, defining how payment references or narrations should be parsed for that partner. This is a raw landed staging table, serving as a direct copy of the Odoo database state for downstream transformation into analytical models.
